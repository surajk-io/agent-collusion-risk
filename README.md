## Active research

- [Research questions](research/research-question.md): **coalitional vulnerability** and **organizational power dynamics**; both remain open.
- [Roadmap](ROADMAP.md): milestones, completion criteria, and **current status for both tracks**.

**Immediate next target (both tracks):** Design the smallest credible organizational workflow, derive a faithful mathematical abstraction, predefine one falsifiable comparison, and plan controls that distinguish collusion from independent or benign behavior. Review the proposed specification *before* writing a new simulator or running agents. The next deliverable is a reviewed proposal, **not** a positive collusion result.
